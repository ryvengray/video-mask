## 一句话概览

客户将待处理视频上传至指定存储位置；多台 GPU Worker 直接下载并并行处理，完成后将打码结果上传回存储。Controller 只管理任务、状态和权限，不中转大视频文件；Ansible 用于批量、可重复地部署和升级 Controller 与 Worker。

> 说明：检测结果会受画面清晰度、遮挡、运动模糊、极端角度、光照及输入视频质量影响。对于隐私风险敏感的正式交付，应按客户实际场景进行抽样验收和人工复核。
